# The register of business rules — the allotment registry (fixture)

*A fixture: the stand-in for the register of business rules kept with the entity model. Every
rule is cited by at least one use case of the fixture's model.*

| Identifier | The rule |
|---|---|
| BR-APP-01 | A resident holds at most one application in a season |
| BR-APP-02 | Only a resident of the town may apply |
| BR-SEA-01 | Applications are accepted only while the application window is open |
| BR-ALC-01 | Plots are allocated in the order the applications were accepted |
| BR-ALC-02 | Every allocation records the reason for it |
| BR-PAY-01 | The rent is paid before the plot is handed over |
