# The entity model — the allotment registry (fixture)

*A fixture: the stand-in for the entity model a real model names, written in its own row of the
specification tree. Names and one-line definitions only.*

| Entity | What it is |
|---|---|
| Resident | A person living in the town who may apply for a plot |
| Plot | One garden plot the registry can allocate for a season |
| Application | A resident's request for a plot in one season |
| Allocation | The decision giving one plot to one application, with its reason |
| Waiting list entry | An accepted application that no free plot could serve |
| Rent payment | The payment of one plot's rent for one season |
| Season | One growing season, with its application window |
