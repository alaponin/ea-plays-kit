# The glossary — the allotment registry (fixture)

*A fixture: the stand-in for the glossary beside the entity model. It carries only terms the
entity model does not name.*

| Term | What it means |
|---|---|
| Application window | The part of a season during which applications are accepted |
| Allocation round | One sitting in which the garden officer allocates the plots then free |
| Residence condition | The condition that only a resident of the town may hold a plot |
