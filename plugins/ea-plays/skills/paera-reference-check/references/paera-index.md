# The map of PAERA, with the public address of each page

Use this file to go from a question to the right page in one step. It gives the section
numbers and the headings of PAERA, and the public address of the page that holds each
one. It does not give PAERA's text. Open the page, read the section, then answer.

The map was read from the public site on 6 October 2026. Section numbers move between
versions. If a section is not where this file says, trust the site, say so, and record
that this file is behind.

**Two ways to read a page.** The address in the tables below opens the page for a
person. Add `.md` to the end of the address to get the same page as plain text, for
example `https://paera.govstack.global/5.-implementation-framework.md`. The plain-text
form is easier for an assistant to read.

**The version.** The courses cite PAERA version 1.0 (GovStack, 2024). On 6 October 2026
the entry page at paera.govstack.global showed no version number and no date. The page
on the specification site showed the label "0.9.0", and both pages showed "Last updated
2 years ago". If step 1 of the skill finds "0.9.0", write that label, the address and
the date that you read it, and say that the courses cite 1.0. Do not record that the kit
is behind: 0.9.0 is not later than 1.0. Record that only when a page shows a version
later than 1.0.

**The licence.** On 6 October 2026 the footer of the page on the specification site
read "Apache-2.0 license". The entry page at paera.govstack.global showed no licence.
This kit does not say what that footer means for a copy of PAERA's text: the licence of
the text is not confirmed. Quote one sentence at most, and give the address.

**Two errors to avoid.** First, a national matter (Chapter 3) is not the job of one body,
and a gap in one body (Chapter 4) is not national policy. Cite the level that you mean.
Second, the foundational pillars of §3.4 are national preconditions. They are not the
same thing as GovStack building blocks, which are reusable software components.
