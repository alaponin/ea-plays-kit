# PAERA sections, and what this kit does and does not carry

## The version this kit records

**PAERA v1.0**, at **paera.govstack.global**. Confirm at run time. Where the published
version differs, use the published one and say so — a PAERA version change is a minor
version bump for this kit, named in the CHANGELOG.

## Why the annex text is not embedded here

The plan for this kit left one question open: whether PAERA v1.0's licence permits verbatim
excerpts of its annexes. Until that is confirmed, this kit **references sections by number
and re-reads the published specification at run time**. That is the plan's own stated
fallback, and it has a side benefit — the check is against the current text rather than
against a copy that ages.

When the licence is confirmed, embedding Annex 2, Annex A1.2 and §5.2 verbatim here is a
minor version bump.

## The five foundations and their sections

The map the August 2026 run produced, and the map this skill reproduces and verifies:

| Foundation (as taught in 1.5) | PAERA section | What to check there |
| --- | --- | --- |
| **Taxonomy** — how public bodies are classified | **§4.6**, with **Annex A1.2** | The seven body types and their definitions |
| **Metamodel** — the shared vocabulary | **Annex 2** | Entity types, relationship types, and what is *not* in it |
| **Building blocks** — the reusable capabilities | The **GovStack building-block catalogue** | Which blocks are specified, at what maturity |
| **Principles** — the ten that govern design | **§5.2** | The principles as worded, all ten |
| **Methodology** — how the work is done | **§5.1, §5.4, §5.7** | The approach, and the recommended roadmap phases |

Cite the section, always. "PAERA says" without a section is the failure the 1.5 safeguard
exists to catch.

None of these is an error in the course. Each is a deliberate reduction for a four-minute
explanation, and each stops being right the moment the output becomes a deliverable.
