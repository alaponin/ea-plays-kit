# Play 1.6 — real-country baseline (The Gambia, 30 August 2026)

Excerpted from `KP1_Play_Tests_Synthesis_2026-08-30.md` §1, the only surviving record
of the runs. Office-holders' names are not reproduced. This file is the comparison
baseline for acceptance criterion 7: *the kit-backed output must be at least as
specific as this on a side-by-side read*.

## What the bare-play run (mostly with the six account skills loaded) produced

The context prompt produced a roles register with a **status tag per role**
(confirmed / partial / gap). The RACI's gaps each carried "blocking from phase N" plus
resolution options. Six gaps, not five.

## What the kit has to match or beat

Two patterns to reproduce: the status tag per role, and phase-blocking plus resolution
options per gap. **The register named real office-holders** because the context prompt asked
for them — the kit's posts-not-names rule exists because of this run, and a kit output that
names a holder fails.
