# Play 4.1 — Build your own demonstration canvas · fixture input

**Consumes:** A0 §6, A12, the sector problem paragraph — from [`tests/progressa.md`](../../progressa.md).
**Primary skill:** `ea-institution-mapper`
**Produces:** A22 — Demonstration canvas

## What the learner types

Build a one-page demonstration canvas for [country X]'s [sector] sector, mirroring the Progressa education example. Produce: (1) the main public bodies and a one-line role for each, classified as policy unit / regulatory agency / service-delivery authority / state registry / shared platform; (2) the fragmentation symptoms likely present — duplicate registries (what is registered more than once), paper re-entry, point-to-point integration, a capability with no clear owner; (3) the 'stalled flagship' — the one cross-cutting outcome a minister has promised that the fragmentation is blocking. Output: a one-page canvas under those three headings, to run the five-phase method against.
