each line below is present. The words are different in each run.

```
> **Artefact** A20 — EA health scorecard · **Country** Progressa · **Sector** Education · **Built** <ISO date>
> **Skill** ea-governance-drafter v<version> · **Consumed** A16, A18 · **Feeds** <play ids from workbook-chain.md>
> **Sources** <n> × Tier 1, <n> × Tier 2, <n> × Tier 3 · **Unverified lines** <n>
```

All nine fields must be present. Write `—` in a field with no value. Never leave it blank.

## The artefact

a one-page scorecard template with metrics, computations and thresholds

## The safeguard, given back as the next action for the learner

A metric you cannot actually measure with available data is worse than none. For each, confirm the data source exists before you commit to reporting it — an invented re-use rate is a number that will be challenged, and once one figure is shown to be made up the whole scorecard loses its credibility.
