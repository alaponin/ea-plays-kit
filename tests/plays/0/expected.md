present; the words will differ every time.

```
> **Artefact** A0 — Country context pack · **Country** Progressa · **Sector** Education · **Built** <ISO date>
> **Skill** country-context-pack v<version> · **Consumed** the country name and sector · **Feeds** <play ids from workbook-chain.md>
> **Sources** <n> × Tier 1, <n> × Tier 2, <n> × Tier 3 · **Unverified lines** <n>
```

All nine fields present. An empty field is `—`, never blank.
